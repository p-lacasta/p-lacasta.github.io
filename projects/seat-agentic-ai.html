Agentic AI for body-in-white manufacturing feasibility

SEAT's body-in-white engineers used to learn whether a part could be manufactured at the end of the process, once the geometry was locked. Building on Synera workflow automation already in production, a multi-agent system now lets designers ask that question during design, with the potential to return a first answer in 30 minutes instead of four weeks. I contributed to the agentic system, building on the CAD/CAE automation work I do at Volkswagen Group Services.

01Problem

Body-in-white development ran in strict sequence: design, then simulation, then manufacturing validation. When simulation flagged a part that could not be made, the geometry was already locked and the cost of changing it had multiplied. The most business-critical question, whether a component can be manufactured, was answered last, when it was most expensive to act on.

02From automation to agents

The agentic system was not built from scratch. It sits on workflow automation that had already proven itself in production.

03Architecture

The design choice that matters most is the split between deterministic workflows and AI agents. Rule-based workflows run the geometry extraction and the forming simulation, so every number is calculated, not approximated by a language model. A supervisor agent orchestrates the run, and specialist agents handle the analysis from those results.

Data connectors

  • CAD
  • Altair simulation tools
  • Material database

The agents work from the same data the engineers use directly.

Deterministic workflows

  • Geometry extraction
  • Forming simulation

Rule-based and repeatable. No language model in the calculation.

Specialist agents

  • Supervisor agent
  • Manufacturing evaluation
  • Simulation
  • Cost
  • CO₂ / product carbon footprint
  • Reporting and presentation

The supervisor calls the specialists in sequence.

04How a check runs

The engineer stays in control of every decision:

  1. A designer uploads a component and asks, in plain language, whether it can be manufactured.
  2. The supervisor agent calls the specialist agents in sequence.
  3. The agents extract the geometry, run the forming simulation and evaluate manufacturability.
  4. The system returns a verdict with the problem areas flagged.
  5. The engineer decides: revise the CAD and resubmit, or ask cost and CO₂ follow-up questions.

05Expected impact and caveats

  • Time. Weeks of simulation queue time recovered per component.
  • Material and cost. Issues are caught before the tooling is locked, when the fix is a CAD edit rather than a six-figure rework.
  • Access. Designers can run a full forming simulation without specialist support, and the knowledge stays encoded for the whole team.
  • Capacity. Simulation engineers are freed for higher-complexity work.

The 30-minute figure is the system's potential time to a first answer, as stated in the public story. It is not my own measurement, and a first answer does not replace the engineer's decision or full validation.

06My contribution

As a Product Engineer in Volkswagen Group Services' PLM Business Services team, I build CAD/CAE automation workflows with Synera, Python and CATIA scripting.
